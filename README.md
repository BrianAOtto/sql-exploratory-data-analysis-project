# sql-exploratory-data-analysis-project

Completed as a guided learning exercise following Baraa Khatib Salkini's *The Complete SQL Bootcamp* — built to practice SQL data exploration, cleaning, and validation.

Performing data exploration, advanced analytics and reporting using SQL Server, including data aggregation and segmentation.

## Files in this repo

**Exploration**
1. **01_database_exploration.sql** — explores the database structure: tables, schemas, and column metadata.
2. **02_dimension_exploration.sql** — explores the structure of dimension tables.
3. **03_date_range_exploration.sql** — determines the temporal boundaries and range of the historical data.
4. **04_measure_exploration.sql** — calculates aggregated key metrics (totals, averages) to spot overall trends and anomalies.

**Analysis**
5. **05_magnitude_analysis.sql** — quantifies data and groups results by dimension to understand distribution across categories.
6. **06_ranking_analysis.sql** — ranks items (e.g., products, customers) to identify top and bottom performers.
7. **07_change_over_time_analysis.sql** — tracks trends, growth, and changes in key metrics over time.
8. **08_cumulative_analysis.sql** — calculates running totals and moving averages to track cumulative performance.
9. **09_performance_analysis.sql** — measures year-over-year and month-over-month performance for benchmarking.
10. **10_data_segmentation.sql** — groups data into meaningful categories for customer, product, or regional segmentation.
11. **11_part_to_whole_analysis.sql** — compares performance and metrics across dimensions or time periods.

**Reporting**
12. **12_report_customers.sql** — consolidates key customer metrics and behaviors into a customer report.
13. **13_report_products.sql** — consolidates key product metrics and behaviors into a product report.

## Skills used
Aggregate functions, window functions, CTEs, views, ranking, segmentation, running totals/cumulative analysis, year-over-year comparison.

## Tools Used
SQL Server (T-SQL).
